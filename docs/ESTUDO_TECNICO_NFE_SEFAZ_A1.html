📑 Estudo Técnico: Emissão Direta de NF-e 4.00 na SEFAZ-SP com Certificado A1

Arquitetura para aposentadoria definitiva do emissor desktop do Sebrae (4.01_sebrae_b053) e emissão direta gratuita no Spring Boot via java-nfe, transmissão síncrona SOAP TLS 1.2 e Certificado Digital e-CNPJ A1.

🏢 Dados de Referência da Empresa Emissora

Razão Social: TOTAL TRIGO COMÉRCIO DE ALIMENTOS LTDA
CNPJ: 09.265.201/0001-95 | IE: 149.932.895.118 | CRT: 3 (Regime Normal)
Status: Validado para Implementação Nativa no 4S ERP (Custo Zero de Mensalidade SaaS)

1. Contexto e Motivação do Projeto

Atualmente, a Total Trigo opera com um fluxo fragmentado e dependente do software desktop Emissor de NF-e do Sebrae (versão 4.01_sebrae_b052 / b053):

Problemas Críticos do Modelo Legado:

  1. Redigitação Humana: Cada pedido fechado na rua precisa ser redigitado manualmente campo a campo no software do Sebrae, gerando risco severo de erros de digitação em CNPJ, razão social, endereço e preços;
  2. Gargalo Operacional: O pedido fica represado aguardando operador disponível para abrir o aplicativo desktop, carregar o certificado e emitir a nota;
  3. Ausência de API: O emissor do Sebrae não possui API REST ou webhooks. A única forma de capturar as emissões para controle de estoque é exportar periodicamente arquivos .zip manuais;
  4. Instabilidade do Software Desktop: Aplicação Java desktop legada que trava em lotes maiores e depende de máquina local específica.

2. Comparativo de Arquitetura: Emissão Direta vs. APIs SaaS de Mercado

Critério de Avaliação Opção 1: Emissão Direta via java-nfe + Certificado A1 (Recomendada) Opção 2: APIs Terceirizadas SaaS (Nuvem Fiscal / Focus NFe)
Custo Mensal Recorrente R$ 0,00 / mês (Custo Zero) R$ 59,00 a R$ 250,00+ / mês (planos por faixa de notas)
Certificado Digital e-CNPJ A1 .pfx existente da Total Trigo e-CNPJ A1 enviado para a nuvem da integradora
Latência e Performance Direta com a SEFAZ-SP (~500ms a 1.5s via chamada síncrona) Duplo salto de rede: App → API Terceira → SEFAZ-SP → API Terceira → App
Dependência de Terceiros Nenhuma (comunicação direta TLS 1.2 com os WebServices SEFAZ-SP) Dependência contratual, suporte externo e risco de indisponibilidade de terceiros
Privacidade e Segurança O certificado e chave privada nunca saem da infraestrutura da Total Trigo A chave privada e a senha residem em servidores de terceiros
Manutenção Tributária Como a Total Trigo opera com apenas 3 SKUs padronizados e regras estáveis de SP (CST 20 / Carga 7%), o esforço de manutenção é mínimo A integradora atualiza schemas de múltiplos estados automaticamente
💡 Decisão Estratégica: Emissão Direta (Custo Zero)

Com o volume de 100 a 300 notas/mês da Total Trigo e o catálogo enxuto de 3 SKUs, a emissão direta via Spring Boot com a biblioteca aberta java-nfe economiza centenas de reais por ano, garante velocidade sub-segundo e mantém o certificado seguro na empresa.

3. Gestão e Ciclo de Vida do Certificado Digital e-CNPJ A1

A Total Trigo possui certificado digital padrão ICP-Brasil e-CNPJ A1 emitido pela autoridade certificadora AC SAFEWEB RFB v5:

  • Tipo: A1 (Software — par de chaves RSA de 2048 bits gravado em arquivo .pfx / .p12);
  • Titular: TOTAL TRIGO COMERCIO DE ALIMENTOS LTDA:09265201000195;
  • Vantagem Operacional: Pode ser carregado em memória pelo Spring Boot em qualquer ambiente (Windows, Linux, Docker, GCP Cloud Run), sem tokens físicos USB.

    Lib->>Lib: Gera Chave de Acesso (44 dígitos, cDV Módulo 11)
    Lib->>Lib: Assina XML (xmldsig C14N + RSA-SHA1 via Certificado A1)
    Lib->>Lib: Valida XML contra XSD local da SEFAZ
    Lib->>SEFAZ: POST SOAP 1.2 com TLS 1.2 (NFeAutorizacao4, indSinc=1)
    SEFAZ-->>Lib: Retorno Síncrono (protNFe: cStat=100, nProt, dhRecbto)
    Lib-->>ERP: XML Autorizado (nfeProc com infNFe + Signature + protNFe)
    ERP->>DB: Salva XML, Chave de Acesso, Protocolo e atualiza Status=FATURADO
    ERP->>ERP: Gera DANFE em PDF
    ERP-->>Operador: NF-e Autorizada com Sucesso! Exibe DANFE e libera romaneio

4.1. Reserva Atômica da Numeração (nNF)

A série utilizada pela Total Trigo é a Série 1 (serie = 1). A última nota emitida registrada no sistema legado do Sebrae foi a 12957 (lote de outubro/2026). O 4S ERP iniciará estritamente na numeração 12958, garantindo continuidade fiscal sem conflito com notas anteriores.

4.2. Transmissão Síncrona para a SEFAZ-SP (indSinc=1)

A SEFAZ-SP processa lotes unitários de forma síncrona via <indSinc>1</indSinc>, devolvendo o protocolo de autorização (cStat=100) na mesma conexão HTTP em menos de 1 segundo.
