🚀 Guia de Implantação e Desenvolvimento

Instruções completas para configurar o ambiente de desenvolvimento local, compilação de código, migrações com Flyway, execução de servidores e resolução de problemas comuns.

💻 Pré-Requisitos de Ambiente

Ferramenta Versão Recomendada Finalidade Comando de Teste
Java JDK 21 LTS Compilação e execução da API Spring Boot 3 java -version
Apache Maven 3.9+ (ou wrapper) Gerenciador de dependências e build Java mvn -v
Node.js & npm Node 18+ / npm 9+ Execução e build do frontend Vite/React node -v e npm -v
Python 3.10+ Robô de automação da planilha de estoque python --version

⚡ Inicialização Rápida (1 Clique)

O repositório inclui um arquivo em lote pré-configurado para inicializar todos os serviços no Windows sem necessidade de comandos manuais: 

iniciar_sistema.bat
🛠️ O que o script realiza em segundo plano:
  1. Inicia o Backend Spring Boot na porta 8085;
  2. Executa as migrações Flyway (V1__init_schema.sql e V2__seed_data.sql) criando tabelas e populando os 3 SKUs e clientes B2B;
  3. Inicia o servidor Vite (Frontend Web) na porta 5173;
  4. Abre automaticamente o navegador padrão em http://localhost:5173.

🔧 Execução Manual dos Componentes

1. Backend (Spring Boot 3)

cd backend
mvn spring-boot:run
  • Porta HTTP: 8085
  • Console do Banco H2: http://localhost:8085/h2-console
  • JDBC URL: jdbc:h2:file:./data/totaltrigo_db;DB_CLOSE_DELAY=-1;AUTO_SERVER=TRUE
  • Usuário: sa | Senha: (em branco)

2. Frontend (React 18 + Vite + Tailwind)

cd frontend
npm install
npm run dev

Acesse no navegador: http://localhost:5173

Para rodar a suíte de testes unitários automatizados:

npm run test

3. Automação da Planilha de Estoque (Python)

cd automacao-planilha
.\executar.bat

Ou utilizando o ambiente virtual Python diretamente:

..\.venv\Scripts\activate
python atualizar_estoque.py

🛠️ Dicas e Troubleshooting

Porta 8085 ou 5173 Ocupada

Se as portas estiverem bloqueadas por instâncias anteriores travadas:

# Identificar PID do processo ocupando a porta:
netstat -ano | findstr :8085

# Finalizar o processo pelo PID:
taskkill /PID <PID> /F

Resetar a Base de Dados Local H2

Para recarregar os dados de demonstração iniciais:

  1. Encerre o backend no terminal;
  2. Apague o arquivo backend/data/totaltrigo_db.mv.db;
  3. Inicie o backend novamente. O Flyway recriará todo o schema e os dados de seed limpos automaticamente.
