🚀 Guia de Implantação e Desenvolvimento — TotalTrigo

Instruções completas para execução em desenvolvimento local, migrações versionadas Flyway (V1 a V4), testes unitários automatizados, orquestração corporativa com Docker Compose e rotinas de backup.

💻 Pré-Requisitos de Ambiente

Tecnologia Versão Mínima Finalidade Comando de Teste
Java JDK 21 LTS Backend Spring Boot 3.4 (Hexagonal REST API) java -version
Apache Maven 3.9+ Compilação, dependências e suíte JUnit 5 mvn -v
Node.js & npm Node 18+ / npm 9+ Frontend React 18, Vite, Tailwind CSS e PWA node -v e npm -v
Docker & Compose Docker 24+ / Compose v2 Ambiente de Produção com PostgreSQL 16 docker --version
Python 3.10+ Automação local de planilha Excel (openpyxl) python --version

⚡ Inicialização Rápida para Desenvolvimento (1 Clique)

O repositório disponibiliza um script automatizado que inicializa todos os serviços com um duplo clique:

📂 Executável Raiz

iniciar_sistema.bat

Abre as instâncias do Spring Boot (porta 8085) com H2 local e Vite (porta 5173), aplicando todas as migrações Flyway automaticamente.

Migrações Versionadas Aplicadas (Flyway)

  • V1__init_schema.sql: Estrutura inicial de produtos, clientes, pedidos e itens;
  • V2__seed_data.sql: Sementes cadastrais das padarias da Zona Sul de SP e lotes de importação;
  • V3__dq_bq_and_dual_stock.sql: Duplo estoque (base_stock), coluna dispatch_quantity (DQ) e frete oficial R$ 4,00/saca;
  • V4__crud_receivables_audit_auth.sql: Tabelas de receivable_titles (boletos bancários) e audit_logs (trilha de auditoria).

🔧 Execução Manual dos Componentes

1. Backend (Spring Boot 3.4)

cd backend
mvn spring-boot:run

Acesse o Console do Banco H2 em http://localhost:8085/h2-console (JDBC URL: jdbc:h2:file:./data/totaltrigo_db;DB_CLOSE_DELAY=-1;AUTO_SERVER=TRUE).

Executando a Suíte de Testes Automatizados (JUnit 5 + Mockito):

cd backend
mvn test

Garante a integridade dos cálculos fiscais (DQ/BQ), frete oficial e faturamento do FiscalDocumentService.

2. Frontend (React 18 + Vite)

cd frontend
npm install
npm run dev

Executa na porta http://localhost:5173 com Hot-Module Replacement (HMR).

Executando Testes Unitários de Frontend (Vitest):

cd frontend
npm run test

3. Automação da Planilha Excel (Python 3)

cd automacao-planilha
.\executar.bat
# Ou via Python com o virtualenv:
..\.venv\Scripts\activate
python atualizar_estoque.py

🐳 Implantação em Produção com Docker Compose

Para disponibilização em servidor corporativo ou VPS na nuvem, o sistema inclui orquestração completa em contêineres:

    DC --> C_BACK["totaltrigo-backend

    DC --> C_FRONT["totaltrigo-frontend

Comandos de Produção:

# Subir os 3 contêineres em modo daemon
docker compose up --build -d

# Visualizar o status de saúde dos contêineres
docker compose ps

# Acompanhar os logs do Backend
docker compose logs -f totaltrigo-backend

💾 Rotinas Automatizadas de Backup do Banco

O sistema inclui scripts para cópia de segurança contínua com retenção de 30 dias:

🪟 Windows (backend/backup_db.bat)

Executa pg_dump com compressão gzip, salvando o arquivo na pasta backend/backups/ e eliminando dumps mais antigos que 30 dias. 

cd backend
.\backup_db.bat
🐧 Linux / Servidor (backend/backup_db.sh)

Script shell compatível com o crontab do servidor para rotinas automáticas de madrugada: 

# Exemplo no crontab (diariamente às 02:00)
0 2 * * * /app/TotalTrigo/backend/backup_db.sh
